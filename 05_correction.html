2 Construction d’un indicateur

Afin de calculer un indicateur de dureté foncière, nous pouvons commencer par faire le ratio entre le bâti et sa parcelle.

Au passage, nous allons montrer comment faire un traitement complexe sous R.

R peut gérer beaucoup de données

2.2 Intersection bati parcelle

La première idée est d’intersecter bat et parcelle afin de récupérer le numéro de parcelle pour chaque batiment.

Mais, l’intersection ne fonctionne pas sous R.

Pour chercher une solution, il faut réduire la donnée.

  • filtrage sur la section A

  • les batiments sont transformés en points

  • ces points sont filtrés sur les parcelles de la section

L’intersection fonctionnera avec 312 points et 284 parcelles

# sauvegarde de l'aire de chaque batiment puisqu'on va transformer les batiments en points.
bat$aireBat <- st_area(bat$geometry)
# filtrage sur une seule section
parcelle <- parcelle [parcelle$section == 'A',]
# on prend le centroid du bat
bat <- st_centroid(bat)
# on identifie les batiments qui intersectent ou pas
dedans <- sapply(st_intersects(bat, parcelle), length)
bat$dedans <- ifelse(dedans > 0 , "oui", "non")

La cartographie permet de vérifier

mf_map(parcelle)
mf_map(bat, type = "typo", var = "dedans", add =T)
mf_layout("Batiments dans ou hors parcelle", "DGFIP, 2024")

L’intersection est enfin possible !

# filtrage sur batiment
bat <- bat [bat$dedans == "oui",]
# intersection
inter <- st_intersection(bat, parcelle)
inter <- inter  [, c("section", "numero",  "aireBat"), drop = T]

Comme il y a plusieurs batiments par parcelles, il faut sommer les aires.

agg <- aggregate(inter$aireBat, by = list(inter$section, inter$numero), sum)
names(agg) <- c("section", "numero", "aireBat")
parcelle$aireParcelle <- st_area(parcelle)

La jointure permet de réunir l’aire des bâtiments par parcelle et la parcelle

joint <- merge(parcelle, agg, by = c("section", "numero"))

2.3 Calcul du ratio et carte

joint$ratio <- joint$aireBat / joint$aireParcelle
mf_map(joint, type = "choro", var = "ratio")
mf_layout("Ratio bâti / parcelle : un début pour l'analyse de la dureté foncière", "DGFIP 2024")
