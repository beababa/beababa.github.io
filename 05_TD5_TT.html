MNS et MNT

Objet

Les images Sentinel sont faciles d’accès et permettent d’évaluer les changements récents.

Pour le MNS et le MNT, la campagne LIDAR de l’IGN qui se termine actuellement a permis de récupérer des données beaucoup plus précises.

Concernant notre problématique spécifique (richesse / pauvreté commune), l’idée est d’examniner les mnt mns de 3 rues importantes de votre commune (pas de départementale), pour voir si la voirie est lisse.

Le MNT issu du Lidar permet-il de repérer les problèmes voirie ?

Définition MNS MNT MNE

Différence entre un MNT / MNS et une image sentinel ?

Définition de la directive européenne INSPIRE

  • MNT surface nue

  • MNS hauteur de tous les objets placés au sol (sursol)

Proposition d’une méthode :

- seuillage (reclassification) : distinguer les pentes > 30 des autres
Code 
pente <- rast("data/cours5/pente.tif")

Code 
reclassif <- matrix (c(-1,30,1,
                       30,90,2),
                     ncol = 3,
                     byrow = TRUE)
pente2 <- classify(pente, rcl = reclassif)
pal <- c("white", "blue")
plot(pente2, col = pal)
